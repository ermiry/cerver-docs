# SHA256

`#include <cerver/utils/sha256.h>`

The SHA-256 hash of cerver, and its hex text. It is a hash, not a way to keep passwords: use a password hashing function, like Argon2 or bcrypt, for those.

## Usage

``` c
char hash[SHA256_STRING_LEN] = { 0 };
sha256_generate (hash, "cerver", strlen ("cerver"));
```

## Reference

``` c
void sha256_calc (uint8_t hash[32], const void *input, size_t len);
void sha256_hash_to_string (char string[], const uint8_t hash[32]);
void sha256_generate (char *output, const char *input, const size_t inlen);
char *sha256_generate_output (const char *input, const size_t inlen);
```

- `sha256_calc ()` writes the 32 bytes of the hash of `len` bytes.
- `sha256_hash_to_string ()` writes the 64 hex characters of 32 bytes and a NUL, in a buffer of at least 65 bytes; it works for any 32 bytes.
- `sha256_generate ()` writes the hex text of the hash of the input, in a buffer of at least 65 bytes.
- `sha256_generate_output ()` returns it in a new string, released with `free ()`.

## Constants

| Constant | Value | What it is |
|---|---|---|
| `SHA256_STRING_LEN` | 80 | A buffer that fits the hex text |
