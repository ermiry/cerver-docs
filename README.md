# Cerver Documentation

Ermiry's Cerver Framework official documentation, published in the [wiki of cerver](https://github.com/ermiry/cerver/wiki).

Each Markdown file of this repository is a page of the wiki, and `_Sidebar.md` and `_Footer.md` are its sidebar and its footer. A push to `main` publishes them with the `wiki.yml` workflow, that needs the `WIKI_TOKEN` secret: a token that can write the contents of `ermiry/cerver`.
